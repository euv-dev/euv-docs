# Markdown 语法

euv-docs 在构建期渲染 VuePress 风格的 markdown 子集。

## 标题

`h2` 与 `h3` 会自动出现在右侧锚点目录。

## 行内格式

支持 **加粗**、*斜体*、~~删除线~~ 与 `行内代码`。

## 列表

- 无序项
- 另一项
  - 嵌套项

1. 有序项
2. 第二项

- [x] 已完成任务
- [ ] 待办任务

## 表格

| 特性 | VuePress | euv-docs |
| --- | --- | --- |
| Frontmatter | ✅ | ✅ |
| 自定义容器 | ✅ | ✅ |
| 锚点目录 | ✅ | ✅ |

## 代码块

```rust
fn fib(n: u64) -> u64 {
    match n {
        0 | 1 => n,
        _ => fib(n - 1) + fib(n - 2),
    }
}
```

## 自定义容器

::: tip
提示容器使用实线边框。
:::

::: warning
警告容器使用虚线边框。
:::

::: danger
危险容器使用双线边框。
:::

::: note 自定义标题
容器支持在类型后写自定义标题。
:::
